Feature Selection Notes¶

  • CYLINDERS was dropped because it is highly correlated with ENGINESIZE (correlation = 0.93), while ENGINESIZE has a stronger correlation with the target variable CO2EMISSIONS.

  • The fuel consumption features (FUELCONSUMPTION_CITY, FUELCONSUMPTION_HWY, and FUELCONSUMPTION_COMB) were removed due to high multicollinearity between them.

  • FUELCONSUMPTION_COMB_MPG was retained because it has the strongest correlation with the target variable (CO2EMISSIONS) with a correlation value of -0.91.

  • FUELCONSUMPTION_COMB and FUELCONSUMPTION_COMB_MPG represent the same property using different measurement units, so they are expected to be strongly negatively correlated.
